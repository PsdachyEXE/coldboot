## Advice carried by the build brief

The brief's exam model (Section 5) lists these points. The first group describes how the 2025 paper was set out. The second group is a Victorian school's advice, and the app presents it as advice, not as VCAA rules.

**From the 2025 paper's format**

- Section C answers must apply to the case study. Generic answers that ignore the scenario score poorly.
- Marks and answer space show the depth wanted: roughly one developed point per mark.
- Command terms set the task. *State* or *identify* wants a brief answer; *describe* wants characteristics; *explain* wants how or why; *justify* wants reasons tied to the scenario; *recommend* wants a choice with its reason.

**Teacher advice (not VCAA rules)**

- Name data types in full: Integer, Floating point, String, Character, Boolean.
- Avoid abbreviations except common ones such as DFD, SRS, XML, CSV and SQL.
- When a question asks for one item, give exactly one. Extra items don't earn extra marks and can cost the mark if one of them is wrong.
